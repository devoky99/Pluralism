Pluralism 0.2.1: Netzwerk überarbeitet, Swift 6. Zielsystem ist **macOS 27**.

**Vorabversion:** kompiliert und automatisch getestet, inklusive einer Netzwerkprüfung von Ende zu Ende auf macOS 27. Mit echten VMs auf einem Mac noch nicht erprobt.

## Behoben

- **Windows-VMs mit Netzwerk starteten nicht.** QEMU suchte für die Netzwerkkarte das PXE-ROM `efi-virtio.rom`, das nicht mitgeliefert war, und brach ab. Die Netzwerkkarte läuft jetzt ohne dieses ROM; die UEFI-Firmware bringt ihren eigenen Treiber mit.
- **Adressbereich blieb belegt.** vmnet-Netze wurden nie freigegeben. Nach dem Ausschalten einer VM blieb ihr Netz bis zum Beenden von Pluralism bestehen. Jetzt werden sie sauber freigegeben.
- **Datenrennen** beim Ausschalten von Windows-VMs (Verbindung zu QEMU wurde geschlossen, während noch gelesen wurde).

## Neu

- **Windows: QEMU legt das Netz selbst an**, mit `vmnet-shared` bzw. `vmnet-host` und dem festen Bereich der VM (z. B. 192.168.160.2), wie es auch UTM macht. Dafür genügt auf macOS 27 das Entitlement `com.apple.security.virtualization`, Root ist nicht nötig.
- **Ausweg Paketbrücke**, falls QEMUs eigenes Netz scheitert: jetzt über einen Stream-Socket statt Datagrammen, damit bei viel Verkehr keine Pakete mehr verloren gehen.
- **Netzwerkprüfung in der CI** spielt einen vollständigen Gast nach: DHCP, DNS, TCP und Ping ins Internet, VM zum Mac, Mac zur VM. Außerdem startet sie das mitgelieferte QEMU mit beiden Netzvarianten.
- **Swift 6:** Der ganze Code läuft im Sprachmodus Swift 6 (Swift 6.4, Xcode 27) mit vollständiger Prüfung auf Datenrennen.

## Hinweis

Programme, die vom Mac aus auf eine VM zugreifen (Terminal mit ssh, Windows App für Remote Desktop), brauchen die Erlaubnis für das lokale Netzwerk. macOS fragt beim ersten Zugriff. Ohne Erlaubnis meldet z. B. ssh „No route to host“. Einstellbar unter Systemeinstellungen › Datenschutz & Sicherheit › Lokales Netzwerk.

## Installation

1. `Pluralism-v0.2.1.zip` herunterladen und entpacken.
2. Einmal im Terminal freigeben (ad hoc signiert):
   ```sh
   xattr -dr com.apple.quarantine Pluralism.app
   ```
3. Nach `/Programme` verschieben und starten.
