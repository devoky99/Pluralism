Erste Version von Pluralism: eigene Virtualisierungs-App für Macs mit Apple Silicon.

**Vorabversion:** Die App ist kompiliert und automatisch getestet, aber noch nicht mit echten VMs auf einem Mac erprobt.

## Inhalt

- **Linux ARM64** über Apples Virtualization.framework: Installation vom ISO, automatische Auflösung, Ton, verschachtelte Virtualisierung, Zustand sichern, ISO im laufenden Betrieb einlegen
- **Windows 11 ARM64** über QEMU mit Hypervisor.framework: vollautomatische Installation mit Treibern, NVMe-Systemplatte, optional TPM 2.0 und Secure Boot, Bild im Pluralism-Fenster mit Mac-Tastenkürzeln
- **Isolation:** keine gemeinsame Zwischenablage, keine geteilten Ordner, keine Gast-Werkzeuge; nur Netzwerk und Peripherie
- Snapshots per APFS-Klon, Klonen, Ressourcenempfehlung für den Mac

## Installation

1. `Pluralism-v0.1.0.zip` herunterladen und entpacken.
2. Die App ist ad hoc signiert. Einmal im Terminal freigeben:
   ```sh
   xattr -dr com.apple.quarantine Pluralism.app
   ```
3. `Pluralism.app` nach `/Programme` verschieben und starten.

Für Windows-VMs zusätzlich: `brew install qemu swtpm`

## Voraussetzungen

Mac mit Apple Silicon, macOS 14 oder neuer (empfohlen macOS 15 oder neuer).
