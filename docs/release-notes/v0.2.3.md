Pluralism 0.2.3: eigenes App-Icon. Zielsystem ist **macOS 27**.

**Vorabversion:** kompiliert und automatisch getestet, mit echten VMs auf einem Mac noch nicht erprobt.

## Neu

- **App-Icon:** Pluralism hat jetzt ein eigenes Icon statt des leeren Standardsymbols. Es zeigt einen Husky aus gefalteten Papierflächen unter Polarlicht. Seine Augen haben zwei Farben (Heterochromie), eines eisblau, eines bernsteinfarben: ein Mac, mehrere Systeme. Das Icon erscheint im Dock, im Finder und im App-Umschalter.
- Die Master-Datei liegt als SVG unter `docs/icon/`. Das Skript `scripts/icon/make-icon.py` erzeugt daraus `Resources/AppIcon.icns` mit allen Größen von 16 bis 1024 Pixel.

## Hinweis

macOS merkt sich App-Icons in einem Zwischenspeicher. Zeigt das Dock nach dem Austausch noch das alte Standardsymbol, hilft einmal `killall Dock` im Terminal.

## Installation

1. `Pluralism-v0.2.3.zip` herunterladen und entpacken.
2. Einmal im Terminal freigeben (ad hoc signiert):
   ```sh
   xattr -dr com.apple.quarantine Pluralism.app
   ```
3. Nach `/Programme` verschieben und starten.
